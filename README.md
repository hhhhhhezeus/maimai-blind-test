# 🎭 麦麦盲测局

在群里发起活动，在个人页面独立评测，最后揭晓身份和真实反馈。适合比较同一主题下的文字、图片和短音频。

## 它能做什么

- 一场活动包含 2–8 个作品。主持人在个人页面投稿，作品的作者、模型或版本信息直到揭晓才对评测者显示。
- 每位群成员的作品顺序独立随机，并在该轮保持固定；每人只能提交一次，提交前看不到其他人的选择。
- 两个问题分别统计「自然」与「符合主题」，均可选「差不多」或「无法判断」。每件作品可以附一条文字意见。
- 主持人揭晓后，群聊可查看票数，个人页面可查看逐件意见。所有反馈来自参与者，不使用模型编造评价。
- 发起复测时关联上一轮，并在结果页并列显示两轮人数和票数。两轮参与者可能不同，票数变化不自动等于质量变化。

## 安装与配置

把仓库目录放入 MaiBot 的 `plugins/`，重启并启用。插件使用 MaiBot SDK 的 `chat.open_session` 和 `send.text`，以及 `ctx.paths.data_dir` 保存 SQLite 数据；Python 标准库即可，不需要大模型或 DGX。

默认页面只监听本机 `127.0.0.1:18762`，其他设备无法访问。部署者需要在插件设置中配置：

| 配置 | 作用 |
| --- | --- |
| `bind_host` | 页面监听地址，例如局域网部署设置 `0.0.0.0` |
| `bind_port` | 监听端口，默认 `18762` |
| `public_url` | 群成员可访问的完整地址，例如 `https://blind.example.com` 或局域网地址 `http://192.168.1.20:18762` |

修改监听地址或开关后重启插件。容器部署还需由部署者映射相应端口；反向代理应保护带令牌的请求并支持最长 15 MB 文件的上传。个人链接是持有者凭证，只能通过私聊发送。群成员必须能访问该页面，且适配器必须允许机器人私聊；公网使用建议配置 HTTPS。初次私聊失败时，请先让群成员与机器人建立私聊。

## 使用

1. 在群里发送 `/盲测 创建 纪录片配音`。麦麦私聊主持人专属链接。
2. 主持人在页面逐件填写揭晓信息并投稿；可提交文字、JPEG/PNG/WebP 图片或 MP3/WAV/OGG/M4A/WebM 音频。单个文件上限 15 MB。添加至少两件后点击「开始盲测」。
3. 群成员在同一个群里发送 `/盲测 参加 活动编号`，收到专属私聊链接后独立完成评测。
4. 主持人在页面点击「结束并揭晓」。群里发送 `/盲测 结果 活动编号` 查看汇总；个人页面展示逐件意见。
5. 修改作品后，在同一个群发送 `/盲测 复测 原活动编号 新主题`，创建关联的新一轮。两轮独立投票和统计。

链接失效时，主持人可在原群发送 `/盲测 管理 活动编号`，评测者再次发送 `/盲测 参加 活动编号` 获取新链接。新链接会使同一人的旧链接失效，但保留其原有随机顺序和已提交状态。主持人不能作为评测者参与自己主持的活动。

## 盲测边界

- 插件隐藏单独填写的揭晓信息、原文件名和提交前的投票统计，但不会修改作品本身或清除图片、音频元数据。请先自行移除水印、声音里的自我介绍和元数据等身份线索。无法防止参与者自行交流或分享链接。
- 支持格式取决于参与者的浏览器，插件不做媒体转码或音频时长检测；建议提前准备较短且浏览器可播放的素材。
- 意见在揭晓后向参与本场的人公开；不要在意见中填写不希望公开的信息。SQLite 数据保存在 MaiBot 分配的插件数据目录中，应按部署者的数据备份和清理策略管理。
- 结果显示实际投票数与原文意见。样本少时只表述本场参与者偏好，不生成客观排名。

## 命令

```text
/盲测 创建 主题
/盲测 管理 活动编号
/盲测 参加 活动编号
/盲测 结果 活动编号
/盲测 复测 原活动编号 新主题
```

所有命令应在活动所在的群聊中使用。
